# サイドバーとツールバーの役割：場所・絞り込み・表示

**実装済み**（下の「実装で決めたこと」）。

使っていて困っていること：

- 絞り込みが 4 か所に散っている。サイドバーのタグとフォントの言語・書体・太さ・特徴、ツールバー 2 段目の評価、
  1 段目のボタンで開く絞り込みバー（形式・追加日・容量）
- サイドバーのフォルダとタグは同じ見た目の行なのに、フォルダは「そこへ移る」、タグは「今の一覧に条件を重ねる」と働きが違う
- 条件を付けると「絞り込み中」の行が増え、一覧が下にずれる（[UI.md](UI.md) の原則に反する）

## 決定

役割を 3 つに分け、置き場所を 1 つずつにする。

| 役割 | 問い | 置き場所 | 選び方 |
|---|---|---|---|
| **場所** | どこを見るか | サイドバー | 1 つだけ選ぶ |
| **絞り込み** | その中をどう絞るか | ツールバーの絞り込みの行（2026-11-14 から開け閉めする） | 重ねて使える |
| **表示** | どう見せるか | ツールバーの「表示」のポップオーバーと見本の文字の行 | 並び順・グループ・レイアウト・大きさ |

| 論点 | 決定 |
|---|---|
| サイドバーのタグ | **場所にする**。フォルダと同じく、押すとそのタグの一覧を開く（1 つだけ）。「フォルダの中をタグで絞る」「複数タグのいずれか／すべて」は絞り込みの行の「タグ」で行う |
| フォントの言語・書体・太さ・特徴 | サイドバーから外し、**絞り込みの行へ移す**。件数は各条件のメニューの中に出す。<br>**（2026-11-05 見直し）** 言語と書体は「どんな種類のフォントか」を見に行く軸なので、**場所としてもサイドバーに置く**（下の「言語・書体の場所」）。絞り込みの行の「言語」「書体」は残す。太さ・特徴は絞る条件なので絞り込みの行だけ |
| 絞り込みの置き場所 | **1 行にまとめる**。「絞り込み中」の行は無くす。**（2026-11-14 見直し）** 行はいつも出すのをやめ、「絞り込み」ボタンで開け閉めする（下の「ツールバー」） |
| 場所を移ったときの条件 | **今のまま**。場所を移ると絞り込みは解除する（同じ場所を選び直したときは残す） |

## サイドバー（場所）

見出し（「場所」「言語」「書体」「フォルダ」「スマートフォルダ」「タグ」）は、上から次の順に並ぶ。

上から次の順。どれも押すとその一覧を開く。

| まとまり | 項目 |
|---|---|
| 見るもの | すべてのフォント、未分類、タグなし、この端末のフォント（読み取り専用。[SYSTEM_FONTS.md](SYSTEM_FONTS.md)） |
| 印 | お気に入り、ピン留め |
| 整理（枠で囲む） | ゴミ箱 |
| 種類 | 言語（日本語・欧文・中国語・韓国語・その他）、書体（明朝・セリフ、ゴシック・サンセリフ、丸ゴシック、スラブセリフ、筆書体、手書き、デザイン、未分類）。フォントがあるものだけを出す |
| 集めたもの | フォルダ、スマートフォルダ、タグ |

- 作業台はサイドバーから外し、「シェルフ」にする（今は詳細パネルのタブ。[FONT_UI.md](FONT_UI.md)）
- タグの行は、選ぶとその行が選択中になる（フォルダと同じ見た目）。タグの名前・色の変更と削除は、今どおり右クリックで行う
- タグの節の見出しにあった「いずれか／すべて」の切り替えは無くす（絞り込みの行の「タグ」へ移る）

### 言語・書体の場所

- 押すとその言語・書体のフォントの一覧を開く（1 つだけ。`View` の `fontScript` / `fontCategory`。`db.rs` の `query_where` が `font_script` / 書体の列で絞る）。書体はユーザーが直した値を優先する（絞り込みと同じ）
- 件数は `counts.fontScripts` / `counts.fontCategories`（取り込んだフォントのうち詳細を読んだもの）。0 件の行は出さない（開いている行は残す）
- 場所の中でも絞り込みの行は使える（「明朝」の中を言語で絞るなど）。ただし **開いている場所と同じ条件**（言語の場所なら「言語」、書体の場所なら「書体」）は繰り返しになるので、消さずに無効表示にし、理由をツールチップに書く（[UI.md](UI.md)）
- 「フォルダの中の明朝」のような組み合わせは、フォルダを開いて絞り込みの「書体」で行う

### 見出し

- 見出しを押すと **節を折りたたむ／開く**。ライブラリごとに覚える（`localStorage` の `collapsed:<ライブラリ>`、フォルダの開閉と同じ入れ物）。折りたたんでいても、いま開いている行だけは残す（どこを見ているか分からなくならないように）。「場所」の見出しは折りたためない
- 見出しの右の操作は、**見出しにカーソルを乗せたときだけ**出す（キーボードで入ったときも出す）。位置は変えない
  - フォルダ・スマートフォルダの ＋：作成（これまでどおり）
  - **タグの ＋**：名前を入力する行が出て、Enter で作成し、そのタグを開く。Esc・空のままで外へ出ると取り消す（作らない）。空のタグを作れる（`create_tag`）。同じ名前があれば、そのタグを開く
  - **「場所」の見出しの右**：「表示するもの」のメニュー。隠せる項目（`SIDEBAR_ENTRIES`）にチェックを付けて並べ、押すと表示・非表示を切り替える。隠したものを戻す入口で、設定画面の「サイドバー」と同じ設定（[SETTINGS.md](SETTINGS.md)）を書く。書く範囲は「いま効いている側」（アプリ全体、またはそのライブラリだけ）で、メニューの上に出す
  - 見出しの右クリックの「サイドバーから隠す」は、これまでどおり

## ツールバー

**ふだんは 1 行目と見本の文字の行の 2 行**。絞り込みの行は利用者が開いたときだけ 3 行目に出る（2026-11-14。Stockroom と同じ考え方：絞り込み・並び順などは部品の中に隠し、いつも使うものだけを出す）。

```text
1 行目  ([サイドバーを表示]) タイトル 件数 [この表示の操作] ……… [絞り込み 2] [表示▾] [検索……] [詳細パネル]
2 行目  見本の文字の行（どのレイアウトでも出す。右端に大きさ）
3 行目  評価▾ タグ▾ 言語▾ 収録文字▾ … ………………… すべて解除 条件を保存   ← 開いたときだけ
```

### なぜ変えたか（2026-11-14）

- 3 段がいつも出ていて、1 段目は真ん中が空いているのに、3 段目には絞り込み 12 個と表示の操作がぎっしり並んでいた
- 並び順・グループ・レイアウトは一度決めたらあまり変えない。絞り込みも毎回は使わない。いつも使うのは見本の文字と大きさ
- 一覧に使える高さを 1 行分増やす

### 1 行目

| 部品 | 決定 |
|---|---|
| サイドバーの開け閉め | **隠すボタンはサイドバーの中**（2026-11-14）。macOS は上端の信号機の帯の右端、帯が無いとき（Windows・全画面）は「場所」の見出しの右。閉じているあいだだけ、ツールバーの左端（信号機の右）に開くボタンを出す。Tab / ⌘⌥1 も今どおり |
| 件数 | タイトルの右はいつも一覧の件数（絞り込み中は「5 / 13 件」）。**選んでいる件数は出さない**（2026-11-14。選択バーと重なり、タイトルが省略される原因だった。[MENUS.md](MENUS.md) §7） |
| この表示の操作 | タイトル・件数の右。フォルダの「サブフォルダの内容も表示」、ゴミ箱の「ゴミ箱を空にする」、この端末のフォントの「読み込み直す」（[UI.md](UI.md)） |
| 絞り込み | 押すと絞り込みの行を開け閉めする。条件を付けているときは塗り（`tonal`）にし、条件の数を出す（「絞り込み 2」）。閉じていても条件は効いたまま |
| 表示 | 今の ⚙ を置き換えるポップオーバー。アイコンは今のレイアウトのもの。中身は下の「表示のポップオーバー」 |
| 外観 | ツールバーから外し、サイドバーの下端の行にした（2026-11-14、[UI.md](UI.md)「色」） |
| 検索・詳細パネル | 今のまま |

大きさ（見本の文字・タイル）は見本の文字の行の右端のまま（[FONT_UI.md](FONT_UI.md)）。

### 絞り込みの行

並ぶ条件は左から：評価、タグ、言語、収録文字、書体、太さ、スタイル数、特徴、軸、形式、追加日、容量。

- **開け閉めは利用者の操作のときだけ**（[UI.md](UI.md) の例外「利用者が自分で開け閉めするもの」）。「絞り込み」ボタン、⌘⇧F（開いて最初の条件へフォーカス）、メニューバーの「表示 › 絞り込みの行」。開いているかは `localStorage` に覚える。初めは閉じている
- スマートフォルダを開いている間（条件を編集している間も）は、その条件を見せるために開いて出す。ほかの場所へ移ったら、利用者が選んでいた開け閉めに戻す
- 閉じたときも条件は外さない。効いていることは、ボタンの塗りと数、タイトルの「5 / 13 件」で分かる
- 条件のボタン・メニュー・件数の数え方は今のまま（下の「条件のボタン」「実装で決めたこと」）
- 右端に「すべて解除」と「条件を保存」（スマートフォルダとして保存）
- 合うものが無いときは、一覧に「条件に合うものはありません」と「絞り込みをすべて解除」を出す
- 狭いときは条件が横にスクロールし、「すべて解除」「条件を保存」は右端に残す

### 表示のポップオーバー

前の ⚙ の中身に、帯に並べていた表示の操作を入れる。上から：

```text
レイアウト        [Aa 見本][▦ グリッド]                         ← セグメント
並び順            [追加日 ▾] [↑↓]
グループ          [なし][書体][言語][年月][評価][タグ][フォルダ]   ← この端末のフォントでは評価・タグ・フォルダを無効表示
──────────
グリッドのタイルの下に表示   ☑ 名前 ☑ 評価 ☑ 形式・容量          ← グリッドのときだけ使える
```

- 選んでもポップオーバーは閉じない（続けていくつか変えられる）。外をクリックするか Esc で閉じる
- 大きさは見本の文字の行にあるので、ここには置かない（同じ操作を 2 か所に置かない）
- 同じものはメニューバーの「表示」にもある（レイアウト・グループ・並び順）。グループの切り替えは 2 クリックになるが、メニューバーとキーで補う
- 実装：`components/ViewMenu.tsx` の `ViewPopover`。1 行目は `components/Toolbar.tsx`（`FilterToggle`）、絞り込みの行は `components/FilterRow.tsx`。
  開け閉めは `store.ts` の `filterRowOpen`（`localStorage` の `filterRowOpen`）と `filterRowShown`、コマンドは `view.filterRow`

### 条件のボタン

- 条件は丸いボタン。押すとメニューが開き、選択肢と件数を出す。件数は **ほかの条件を付けたまま** 数える
- 使っている条件は塗り（アクセント色）にし、値を出す（例「タグ 本文・見出し」）。▾ の位置に × を出して、その条件だけ解除できる。
  値が長いときは省略し、隣の条件を押し出さない（[UI.md](UI.md)）
- 1 つの条件の中で複数選んだものは「いずれか」。条件どうしは「すべて」
  - 評価は「★n 以上」から 1 つ、追加日は期間から 1 つ選ぶ
  - タグは「いずれか／すべて」をメニューの中で切り替える
- スマートフォルダを開いているときは、その条件を絞り込みの行に読み込んで表示する（「条件を編集」で変えられる）

## 実装で決めたこと

| 論点 | 決定 |
|---|---|
| 件数の数え方 | `facet_counts`（`db.rs`）が今の問い合わせに合うものを条件ごとに数える。各メニューは開いたときに、その条件だけを外した問い合わせ（`listQuery(s, key)`、`store.ts`）で数え直す。開いたまま別の条件を変えたら数え直す |
| 「5 / 13 件」の分母 | その場所の件数（サイドバーと同じ数。サブフォルダ表示ならその合計、`placeTotal`） |
| 狭いとき | 行は 1 行のまま。条件は横にスクロールし、「すべて解除」「条件を保存」は右端に残す。メニューはウィンドウに対して出す（行で切れない） |
| ~~表示の行が狭いとき~~ | 2026-11-14 に表示の操作を「表示」のポップオーバーへ移したので無くなった |
| 「タグ」のメニュー | タグが 9 個以上あれば上に検索欄を出す。「いずれか／すべて」はメニューの上端 |
| 「すべて解除」 | 検索欄の文字も含め、絞り込みの行の条件をすべて外す |
| 収録文字（2026-11-05） | 入力した文字を **すべて収録している** フォントだけを残す（空白は数えない）。メニューは入力欄と「見本の文字から入れる」「消す」。取り込み時に、先頭のフォントが持つ文字を **コードポイントの範囲** にして `items.font_chars`（BLOB）に保存し（`fonts::coverage`。ふつう数百バイト、日本語のフォントで数 KB）、SQL 関数 `covers(font_chars, 入力)`（`db.rs` の `register_functions`）で調べる。NULL = まだ読んでいない（読み直す。移行の 3 つ目の段）。件数は数えない（自由入力のため）。スマートフォルダの条件にもなる |
| 端末のフォントの収録文字 | まだ使えない（ボタンは消さず無効表示にし、理由をツールチップに書く）。端末のフォントの文字の表は、一覧を読むときに持っていないため |
| スタイル数（2026-11-05） | そのフォントの **ファミリーの大きさ**：同じファミリー名のフォントの数（ゴミ箱のものは数えない。ファミリー名が無いフォントは 1）。「1」「2〜3」「4〜8」「9 以上」と、「細〜太をそろえる」（ファミリーが Light 以下から Bold 以上までそろっている）から選ぶ。`db.rs` の `FONT_STYLES`。一覧のファミリー行の「N スタイル」と同じ数え方 |
| 軸（2026-11-05） | 可変フォントの軸。太さ（wght）・幅（wdth）・光学サイズ（opsz）・イタリック（ital）・斜体の角度（slnt）・そのほかの軸から選ぶ（いずれか）。取り込み時に軸の一覧を `items.font_axes` に保存する（空文字 = 可変でない、NULL = まだ読んでいない）。既存のライブラリは、次の起動で NULL のフォントを読み直す（`missing_font_meta`。移行の 2 つ目の段） |
| カラーフォント（2026-11-05） | 「特徴」に足す。COLR・SVG・CBDT・sbix のいずれかの表を持つフォント（`fonts::features` の `color`）。軸と同じ読み直しで、既存のフォントにも付く |
| 端末のフォントの軸・スタイル数・カラー | ライブラリと同じ条件で絞れる。軸は一覧を読むときに取り（`SystemFont.axes`、キャッシュの版を上げて読み直す）、スタイル数は端末のフォントのファミリーの数で数える（`system.ts`） |
| タグの場所で「条件を保存」 | 開いているタグも条件に入れて保存する（保存したスマートフォルダが同じものを集めるように） |
| スマートフォルダを開いているとき | 条件は塗りのボタンで出すが、押しても変わらない（押すと「条件を編集」と同じく編集に入る）。検索の文字は「検索」のボタンで出す。右端は「条件を編集」。編集中は「「名前」の条件を編集中」と「キャンセル」「保存」 |
| ⌘⇧F | 絞り込みの行を（閉じていれば開いて）、使える最初の条件へフォーカスを移す（メニューバー「編集」→「絞り込みへ」） |
