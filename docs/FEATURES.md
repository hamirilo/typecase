# 機能と使い方

## 機能

- **インポート**：ウィンドウへのドラッグ&ドロップが主な動線。ほかにメニューバーの「ファイル」→「追加…」「フォルダから追加…」、クリップボードから貼り付け（⌘V / Ctrl+V）。一覧が空のときは画面の中央にも「追加」を出す
  - フォルダを取り込むと **フォルダ構造をそのまま再現**（同名フォルダは再利用）
  - サイドバーのフォルダに直接ドロップすると、そのフォルダへ入る
  - 同じフォント（SHA-256 一致）は重複としてスキップ。ゴミ箱にあるものは復元される（すでに別フォルダにあるものは移動しない）
  - 対応形式：TTF / OTF / WOFF / WOFF2 / TTC / OTC。ほかのファイルは取り込まない
- **一覧**：サムネイルサイズ変更、範囲ドラッグ選択、仮想スクロール。ゴミ箱へ移動（⌘⌫）すると次の項目が選ばれ、ビューアを開いたままでも続けて削除できる
  - 絞り込みと同じ帯の右端で、並び順・グループ分け・レイアウト・表示（見本の文字・タイルの大きさ、下に出す情報）を切り替える。ウインドウが狭いときは決めた順に畳まれ、行は増えない（docs/UI.md「操作の帯」）
  - レイアウト：［見本｜グリッド］のボタン。リストは無い（見本の文字を小さくすれば代わりになる）。docs/FONT_UI.md
    - **見本の文字の行**（ツールバー 2 段目）はどのレイアウトでも出す。入力した文字が全部のフォントに反映され（空欄なら各フォントの見本）、フォントに無い文字は赤い点線で示す。
      入力した文字の半分以上が無いフォント（英語フォントに日本語の文章など）は、そのフォントの見本で表示し「欧文見本」などの印を付ける（「パターン」のメニューの「足りないフォントは各フォントの見本で」で切り替え。ビューアは置き換えない）
    - 右端のスライダー（⌘+ / ⌘-）は、見本では文字の大きさ（12〜160px）、グリッドではタイルの大きさ（120〜320px）
    - 「パターン」のボタンに今のパターンの名前を出す。メニューは「何を確かめるか」の見出し（和文・欧文・数字・記号・混植）で分け、
      数字・記号は半角と全角を別にする。先頭は **自分のパターン**（「今の文字を保存」で入力欄の文字を保存、行の × で消す。ライブラリごと）
    - 見本：1 ファミリー 1 行。名前・スタイル・評価・書体などの行と、見本の文字（画面に見えている行のフォントだけを読み込む）
    - グリッド：1 ファミリー 1 枚のタイルに、見本の文字（入力が無ければ「あ永A」／欧文は「Aa」）をそのフォントで描き、名前とスタイル数を添える
  - **ファミリー**：フォントの一覧は常にファミリー単位（代表は Regular。操作はファミリー全部に効く）。スタイルが 2 つ以上ある行は ▸ で、
    その行のすぐ下に太さ違いを細い順に開き、それぞれ 1 つのフォントとして選択・評価・シェルフへの追加ができる（開いた状態はアプリを閉じるまで。グリッドでは開かない）
  - **この端末のフォント**（サイドバーの「見るもの」）：この端末にインストールされているフォントを、ライブラリに取り込まずに同じ見本・グリッド・ビューア・詳細で見られる。
    読み取り専用で、言語・書体・太さ・特徴・形式の絞り込み、名前の検索、書体・言語のグループ分け、Finder / エクスプローラで表示が使える。
    評価・タグ・フォルダ・メモ・書き出しはライブラリのフォントだけ（無効表示）。初めて開いたときに OS のフォントのフォルダを読み、
    次からは変わったファイルだけを読み直す（ツールバーの「読み込み直す」で、インストール・削除したフォントを反映）。docs/SYSTEM_FONTS.md
    - **シェルフ・比較**にも置け、ライブラリのフォントと並べて比べられる（ドラッグはシェルフへだけ）。シェルフはライブラリに残るので、
      別の端末で開いてそのフォントが無ければ名前だけを取り消し線で出す
    - ライブラリと端末に同じフォント（PostScript 名が同じもの）があれば、ライブラリ側に「インストール済み」、端末側に「ライブラリにある」の印が付く
  - タイルの下に出す情報（名前・評価・形式と容量）を切り替え
  - **グループ分け**：ツールバーのセグメントで 1 クリック（選択中は塗り）。［なし｜書体｜言語｜評価｜タグ｜フォルダ｜月］。
    月は追加日（取り込んだ日）で分け、新しい区切りが上（この端末のフォントには使えない）。評価は ★5〜未評価、タグは複数タグのものを各タグに表示（ファミリーはどれかのスタイルに付いたタグに出る）、フォルダは「すべて」やサブフォルダ表示で便利。区切りの見出しをクリックするとその区切りをまとめて選択
  - 並び替え：追加日・名前・ファイルサイズ・評価・**手動**（フォルダ内でドラッグして並べ替え）
  - 「サブフォルダの内容も表示」でフォルダ配下をまとめて表示
- **整理**：入れ子フォルダ（1 つのフォントは 1 つのフォルダにだけ入る。複数の分類にはタグを使う）、タグ（補完付き）、メモ、**★評価（0〜5）**
  - **お気に入り**（F、見本の行・タイルのハート）とは別に **ピン留め**（P）があり、ピン留めしたフォントはどの一覧でも先頭に表示される。サイドバーの「お気に入り」「ピン留め」でまとめて見られる
  - キー・メニュー・ツールバーで評価・お気に入り・ピン留めをすると、画面の下に何をしたか（「★★★☆☆ 評価 3　2 件」など）が少しのあいだ出て、変わった行が一瞬光る（ハートや星を直接クリックしたときは出さない）
  - フォルダ・スマートフォルダ・タグに **色** を付けられる（サイドバーで右クリック → 色の行から選ぶ。9 色）
  - フォルダの順番は自由に変えられる（行の上端・下端へドロップ、⌘[ / ⌘]）。右クリックで名前順に戻す
  - サイドバーのフォルダは ⇧+クリック（範囲）・⌘+クリック（1 つずつ）で複数選び、まとめてドラッグして移動・並べ替えできる
  - タグのコピー／貼り付け（⌘⇧C / ⌘⇧V）
  - フォントをサイドバーのフォルダへドラッグ、または **フォルダ移動ダイアログ**（⌘⇧J：検索・新規作成）
  - Shift+D で直前に使ったフォルダへ移動、「選択から新規フォルダ」
- **場所**：サイドバーは「どこを見るか」を 1 つ選ぶ場所。上から すべてのフォント・未分類・タグなし・この端末のフォント／お気に入り・ピン留め／
  ゴミ箱（枠で囲む）／言語・書体／フォルダ・スマートフォルダ・タグ。タグもフォルダと同じく、押すとそのタグの一覧を開く（docs/NAVIGATION.md）
  - 言語（日本語・欧文…）と書体（明朝・ゴシック…）も場所として開ける。フォントがあるものだけ並び、件数が付く。その場所の中では、同じ条件（言語の場所なら「言語」）の絞り込みは使えない
  - 見出し（言語・書体・フォルダ・スマートフォルダ・タグ）を押すと節を折りたためる（開いている行は残る）。カーソルを乗せると出る ＋ で、フォルダ・スマートフォルダ・タグを作れる。「場所」の見出しのメニューで、隠した項目を戻せる
- **検索・絞り込み**：名前・ファミリー名・メモ・タグ名を検索（`-語` で除外、`A OR B` / `A || B`、`( )`、`"語句"`）
  - **絞り込み**（ツールバーの帯の左側、常に出ている）：評価・タグ・言語・書体・太さ・特徴・形式・追加日・容量。
    丸いボタンを押すとメニューが開き、選択肢ごとに **ほかの条件を付けたままの件数** が出る。使っている条件は塗りで値を出し、× でその条件だけ外せる。
    1 つの条件の中は「いずれか」（タグはメニューで「すべて」にも切り替え）、条件どうしは「すべて」。⌘⇧F で行へフォーカス
  - 絞り込み中はタイトルの件数が「5 / 13 件」になる。「すべて解除」で検索と条件をまとめて外せる（狭いときは ⋯ のメニューの中）（場所を移ると自動で解除）
  - **スマートフォルダ**：絞り込みの行の「条件を保存」で今の条件（検索・タグ・評価・絞り込み）を保存すると、当てはまるものが自動で集まる。
    開くと条件が絞り込みの行に出て、「条件を編集」（または右クリック →「条件を編集」）で変更
- **ビューア**：入力した文字を好きな大きさで試す（下の「フォント」）。← → で前後のフォントへ
  - 詳細パネル（I）で名前・ファミリー・タグ・フォルダ・メモを確認し、評価・お気に入り・ピン留めを変更。下部のサムネイル（T）で前後のフォントへ移動。1〜5 / F / P のキーも一覧と同じ
- **フォントの絞り込み**：絞り込みの行に **言語**（日本語・欧文・中国語・韓国語・その他）、**収録文字**（入力した文字をすべて持つフォント。ライブラリのみ）、**書体**（明朝・セリフ／ゴシック・サンセリフ／丸ゴシック／スラブセリフ／筆書体／手書き／デザイン／未分類）、**太さ**（細い Thin–Light 〜399／標準 Regular–Medium 400〜549／太い SemiBold–Bold 550〜749／極太 ExtraBold–Black 750〜。メニューにはウェイト名を添える）、**スタイル数**（ファミリーが 1／2〜3／4〜8／9 以上のスタイル、細〜太をそろえる）、**特徴**（等幅／プログラミング向け／可変フォント／イタリック・斜体／カラーフォント）、**軸**（可変フォントの太さ・幅・光学サイズ・イタリック・斜体の角度）が並ぶ。メニューには 0 件の項目も出す。同じ条件の中は「どれか」、条件どうしは「すべて」。スマートフォルダの条件にもなる
  - 言語は含まれる文字から判定。書体はフォント名（「明朝」「Gothic」「Rounded」「Slab」「楷書」「手書き」など）とフォント内の分類情報から自動で判定し、分からないものは「未分類」。詳細パネルの「書体」で選び直せる（複数のフォントを選んでまとめて設定も可）
  - 太さはフォントのウェイト（100〜900）。可変フォントは wght 軸がまたがる範囲すべてに数える
  - 特徴は自動で判定：等幅はフォントの指定か欧文字の送り幅が揃っていること、プログラミング向けは等幅のうち名前（Code・Mono 系の有名なもの）か「半角の 2 倍が全角」の送り幅かスラッシュ付きゼロ（zero 機能）を持つもの、可変フォントは可変軸があるもの、イタリック・斜体はフォントの指定
- **フォント**：見本（"Aa" と、含まれる文字に合わせて「あア永」か "ABC abc 123"）を描いたサムネイルを持つ
  - ビューアで、入力した文字を好きな大きさで試せる（12〜200px、小さいサイズの見本も表示）。フォントに無い文字は赤い点線付きで示す（システムのフォントで代わりに表示されるため）。含まれる文字の一覧（先頭 3000 字まで）
  - ファミリー名でも検索できる。太さごとに別ファイルのフォント（Light / Regular / Bold …）は 1 行にまとまり、▸ で開いて見られる。幅違い（Compressed / Condensed / Extended / Wide など）は別ファミリーになる（「ヒカリ角ゴ Compressed」）。ファミリー名に太さが入ったフォント（「MOBO-Bold」「〜ボールド」）も、太さを取り除いてまとめる
  - 詳細パネルにファミリー・スタイルと太さ・文字数・製作者・版。可変フォントは軸（太さ 100〜900 など）と名前付きスタイルの数、TTC / OTC は中のフォントの一覧
  - TTC / OTC は 1 ファイル = 1 件。ビューアで中のフォント（W3 / W6 など）を切り替えて見る
- **持ち出し**：⌘C でクリップボードへ（ファイル）、ウィンドウの外へドラッグして他のアプリへ、既定のアプリで開く、フォルダへ書き出し。「ファイル」→「ライブラリ全体を書き出し…」で、ゴミ箱以外のすべてを `<ライブラリ名>/<フォルダ>/…` のようにフォルダ構成どおりにコピーする（バックアップとは別。[EXPORT.md](EXPORT.md)）
- **シェルフ**：詳細パネルのタブ（［情報｜シェルフ］）。比べたいフォントを一時的に置いておく（docs/FONT_UI.md）
  - B キー（もう一度で外す）、右クリック →「シェルフに追加」、詳細パネルのボタン、シェルフへのドラッグ、見本の行・タイルのホバーのボタンで追加
  - タブは自分で押したとき（⌘I で情報、⌘⌥3 でシェルフ）だけ変わる。一覧からドラッグしているあいだだけシェルフを出し、終われば戻す（パネルを閉じていれば一覧の右に重ねて出す）
  - 並びは入れた順に縦に並ぶ。シェルフの中で上下にドラッグして並べ替えられる。クリックで一覧のその項目を選ぶ
  - **8 件まで**（空きの枠を点線で出す。9 件目は知らせて追加しない）。ファミリーの行は代表の 1 件として置き、▸ で開いた太さ違いはそれぞれ置ける。操作は「空にする」「比較する」
  - 「空にする」はシェルフから外すだけで、中身は消えない（元に戻す可）。ライブラリごとに保存され、アプリを閉じても残る
  - 右クリックで「別のライブラリへ…」も
- **比較**：シェルフの「比較する」で、一覧の場所に並べて比べる。「一覧へ戻る」か Esc で戻る
  - フォントを行に固定。左に名前・書体・比べる太さ（ファミリーのスタイルから選ぶ）・評価・お気に入り（お気に入りは左端に緑の線）・×（シェルフから外す）
  - 和文フォントは 1 行目に英数（1 行に収め、はみ出しは省略）、続けて選んだ観点（かな・漢字・見出し・本文・約物・混植。初めはかな・漢字・約物・混植）を区切らずに 2 行まで。
    「自分の文字を足す」の文字は先頭。観点のまとまりにはホバーで観点の名前を出す
  - 欧文フォントは英字と数字・記号の 2 行で、和文は出さない（自分の文字が英数だけなら間に 1 行足す）
  - 背景は暗／明、文字の大きさは 14〜72px（初期値 24px）
- **ゴミ箱**：⌘⌫ / Delete で移動（元に戻す可）、復元・完全削除
- **ウィンドウ**：閉じたときの大きさ・位置・最大化を覚えていて、次はその状態で開く（そのディスプレイが無いときは位置だけ戻さない）
  - macOS はタイトルバーの帯を無くし、閉じる・最小化・拡大のボタンをサイドバーの上に重ねる。ツールバーの空いたところ・サイドバーの上端をつかんで移動、ダブルクリックで拡大。ウィンドウ枠やダイアログは OS の設定によらずダーク
  - macOS はサイドバーが半透明（Finder と同じ、後ろの画面がぼけて透ける）。ウィンドウが裏にあるときは不透明な灰色
- **二重起動しない**：起動中にもう一度開くと、新しく起動せずに今のウィンドウを前に出す（1 つのアプリで開けるライブラリは 1 つ。切り替えはメニューの「最近使ったライブラリ」かサイドバー下部）
- **OS の通知**：10 秒以上かかった取り込み・別のライブラリへのコピー／移動・書き出しが、ほかのアプリを使っている間に終わったら、OS の通知で知らせる
- **ログ**：警告・エラーをファイルに残す。ヘルプ →「ログを表示」（macOS は `~/Library/Logs/com.local.typecase/`、Windows は `%LOCALAPPDATA%\com.local.typecase\logs\`）。1 MB ごとに切り替え、古いものは 2 つまで残す

## ライブラリの構造

ライブラリは 1 つのフォルダで完結しているので、フォルダごとコピーすればバックアップ・別 PC への移動ができる。

```
MyFonts.library/
  library.db                 # SQLite（フォルダ・タグ・メモなど）
  fonts/<id>/<元のファイル名>   # 取り込んだフォントのコピー
  thumbs/<id>.png             # 見本を描いたサムネイル
  library.lock               # アプリで開いている間だけ（開いている PC の名前と、2 分ごとに更新する時刻）
```

## バックアップ

- **アプリを終了してから** `.library` フォルダごとコピーする。起動中は SQLite の作業ファイル（`library.db-wal` / `-shm`）に未反映の変更があるため、途中の状態を写してしまうことがある。
  アプリは終了するとき・ほかのライブラリに切り替えるときに、変更をすべて `library.db` に書き込んでから閉じる
- Time Machine はそのままで良い（APFS のスナップショットで一貫した状態が保存される）
- 取り込んだフォントのファイルは後から変わらないので、差分コピー（`rsync -a` / `robocopy /MIR` など）なら 2 回目以降は新しいフォントだけが写る
- iCloud Drive・Dropbox・OneDrive などの同期フォルダは、**バックアップのコピーを置く先**として使うのが安全
- 同期フォルダの中のライブラリを複数の PC で使うときは：
  - **開くのは 1 台ずつ**。開いている間は `library.lock` があり、ほかの PC で開こうとすると「◯◯で開かれています」と確認が出る（同期が遅れて届かないこともあるので、頼り切らない）
  - **アプリを終了し、同期が終わってから**もう一方で開く
  - 元ファイルを「オンラインのみ」にしない（iCloud の「Mac ストレージを最適化」、OneDrive の「ファイル オンデマンド」は、ライブラリのフォルダを「常にこのデバイスに保持」に）
- NAS・社内のファイルサーバーに置いたライブラリを、**複数人で同時に開かない**（SQLite の WAL はネットワーク越しの同時アクセスに対応していない）
- 戻すとき：コピーしたフォルダを置き、「既存のライブラリを開く」で選ぶ

最後に開いたライブラリのパスはアプリ設定（macOS: `~/Library/Application Support/com.local.typecase/settings.json`）に保存される。
