# フォントの絞り込み：Adobe Fonts / Google Fonts の調査

Typecase の絞り込み（評価・タグ・言語・書体・太さ・特徴・形式・追加日・容量）に足す条件を探すため、
Adobe Fonts と Google Fonts の探し方を調べた（2026-11-05）。決定ではなく、候補の整理。

## 確かめた範囲

| 対象 | 確かめ方 | 確度 |
|---|---|---|
| Google Fonts | 公開メタデータ `fonts.google.com/metadata/fonts`（1,959 ファミリー）を直接集計 | 高い（実データ） |
| Adobe Fonts | `fonts.adobe.com/fonts` の HTML（絞り込みは JS で描くので項目は取れず）。項目は前回の検索要約・コミュニティ記事による | 中〜低い |
| Illustrator のフォントブラウザ | `helpx.adobe.com` は 403（アクセス拒否）。公式の説明は読めていない | 低い（二次情報） |
| Typeface（Mac のフォント管理アプリ） | `typefaceapp.com` のトップを読んだ | 中 |

## Google Fonts（実データ）

- **カテゴリ**：Sans Serif 722 / Display 474 / Handwriting 358 / Serif 354 / Monospace 51。
  別に `stroke`（Sans Serif / Serif / Slab Serif）と `classifications`（Display / Handwriting / Monospace / Symbols）を持つ。
  Typecase の書体（明朝・ゴシック・丸ゴシック・スラブ・筆書体・手書き・デザイン）とほぼ対応する。
- **言語**：`subsets`（文字の範囲）で絞る。182 種。日本語・韓国語・中国語（簡体・繁体）もある。
- **バリアブル**：565 ファミリーが軸を持つ。軸は `wght` 548、`wdth` 100、`opsz` 29、`slnt` 23、ほか装飾軸（ELSH・CRSV・ROND など）。
  軸ごとに絞れる（レジストリに軸の名前・範囲・既定値がある）。
- **カラー**：COLRV0 / COLRV1 / OTSVG を持つものが 21 ファミリー。
- **スタイル数**：1 件 1,037 / 2 件 131 / 4 件 175 / 9 件 124 / 18 件 83。並べ替えにも使える。
- **ほか**：人気順・新着・デザイナー・追加日・更新日・オープンソースか。
- 画面には「入力した文字を含むフォントだけにする」機能もある（文字で探す）。

## Adobe Fonts（二次情報を含む）

- **雰囲気のタグ**：用途や印象の言葉（やわらかい・力強い…）。Adobe が書体に付ける語彙。
- **分類**：セリフ・サンセリフ・スラブ・スクリプト・手書き・等幅など。
- **プロパティ**：太さ・幅・x-height・コントラスト・大文字小文字・数字の形。
- **言語・書字体系**：ドロップダウン。
- **技術**（Illustrator）：TrueType / OpenType / バリアブル / カラー / SVG。
- **条件の組み合わせ**：重ねがけは「すべてに合う」。ファウンドリと分類は同時に使えない（コミュニティの報告。2024 年時点）。
- `fonts.adobe.com` のトップには「バリアブルフォント」の特集がある（雰囲気のタグの 1 つの扱い）。

## Typeface（Mac のフォント管理アプリ）

近い立場のアプリ。タグは「組み合わせ・反転」ができ、複数のフォントへ一度に付けられ、書き出せる。
絞り込みは分類・特徴に加え、**必要な文字を指定して絞る**ものがある。

## Typecase に足す候補（優先順）

現状のコードは `fonts/mod.rs` に `glyphs`（グリフ数）と `axes`（バリアブルの軸）を持つ。

| # | 候補 | 出どころ | 実装の目安 |
|---|---|---|---|
| 1 | **この文字を持つフォント** | Google / Typeface | 見本の入力欄の文字を `cmap` で引く。取り込み時に収録範囲を取るか、絞り込み時に読むか決める |
| 2 | **バリアブルの軸**（太さ・幅・斜体・光学サイズ） | Google / Adobe | `axes` が既にある。「特徴」にバリアブルはあるので、軸の絞り込みを足す |
| 3 | **スタイル数・太さの範囲** | Google | 同じファミリーの太さを数える。並べ替えにも足せる |
| 4 | **カラーフォント** | Google / Adobe | COLR / SVG / sbix / CBDT テーブルの有無。「特徴」に足す |
| 5 | **雰囲気のタグ** | Adobe | Adobe 固有の語彙で、フォントの中身からは取れない。自分のタグ（既存）と別にする意味は薄い。見送りが妥当 |
| 6 | **形の性質**（x-height・コントラスト・数字の形） | Adobe | 計測が要る。優先度は低い |

画面に足すときは [UI.md](UI.md) の原則（絞り込みの帯の位置・折りたたみの順）に従う。

## 実装した条件（2026-11-05）

候補 2〜4 を絞り込みの行に実装した。決めたことは [NAVIGATION.md](NAVIGATION.md)「実装で決めたこと」。

| 候補 | 置き場所 |
|---|---|
| 1 この文字を持つフォント | 絞り込みの「収録文字」 |
| 2 バリアブルの軸 | 絞り込みの「軸」 |
| 3 スタイル数・太さの範囲 | 絞り込みの「スタイル数」（太さの範囲は「細〜太をそろえる」） |
| 4 カラーフォント | 絞り込みの「特徴」の「カラーフォント」 |

候補 1「この文字を持つフォント」も実装した（絞り込みの「収録文字」。ライブラリのフォントのみ。端末のフォントは未対応）。5・6 は見送り（上の表のとおり）。
