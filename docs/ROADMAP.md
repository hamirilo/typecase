# ロードマップ

Typecase の機能追加の計画。Stockroom から分かれたときの計画のうち、フォントにかかわるものだけを残した。
方針は変えない：**取り込んだ元ファイルは書き換えない**。

規模の目安：S = 1〜2 日、M = 3〜5 日、L = 1〜2 週間以上。

## 一覧（優先順）

| 項目 | 現状 | 規模 |
|---|---|---|
| フォントの取り込み（TTF / OTF / WOFF / WOFF2 / TTC / OTC） | **実装済み** | M |
| この端末のフォント（取り込まない読み取り専用の一覧） | **実装済み**：一覧・見本・絞り込み、シェルフ・比較、ライブラリとの印。ライブラリへの取り込みはやらない（[SYSTEM_FONTS.md](SYSTEM_FONTS.md)） | M |
| シェルフと比較 | **実装済み**（[FONT_UI.md](FONT_UI.md)） | M |
| ライブラリ全体の書き出し | **実装済み**（[EXPORT.md](EXPORT.md)） | S |
| ファイル名の一括変更 | 1 件ずつの名前変更のみ（`rename_item`） | S |
| スマートフォルダのルール編集 UI | 一覧上部の検索・絞り込みの状態をそのまま保存する形 | M |
| Stockroom のタグ・評価・メモを引き継ぐ取り込み | 未定。今はフォントを書き出して取り込み直す（README） | M |

対応済みのもの：

- **色分け**：フォルダ・スマートフォルダ・タグに 9 色。今のままで十分なので追加はしない。

## フォント（実装済み）

**決定**：TTF / OTF / WOFF / WOFF2 / TTC / OTC に対応する。

- 完全一致の重複判定（SHA-256）で、同じファイルは取り込まない
- サムネイル：サンプル文字（"Aa あア 永"）を Rust（resvg）で描画して PNG を作る
  - WOFF / WOFF2 は展開してから描画する
- TTC / OTC：**1 ファイル = 1 件** として扱う。サムネイルは最初のフォント、ビューアと詳細パネルで中のフォントを切り替える
- ビューア：`@font-face` で読み込み、任意の文字を入力・大きさを変えて確認。文字の一覧
- 詳細パネル：ファミリー名・スタイル・グリフ数・（TTC なら）含まれるフォントの一覧
- 持ち出し：⌘C・ドラッグ・書き出しは元ファイルのまま。形式の変換はしない

## ファイル名の一括変更（S）

- 選択中のフォントに対して「名前を一括変更…」ダイアログ（複数選択時の F2）
- 方式：テンプレート（`{name}` `{n}` 連番 `{date}` `{family}` `{ext}` `{folder}`）／置換（正規表現の有無）／前後に追加
- 変更前 → 変更後のプレビュー、重複する名前の警告、元に戻す
- 名前は DB 上の表示名だけで、ディスク上のファイルは変えない（安全）。書き出し時のファイル名はこの表示名を使う

## スマートフォルダのルール編集 UI（M）

今は「一覧上部の検索・絞り込みの状態 = ルール」で、保存した条件が見えにくく、「すべて／いずれか」の切り替えはタグにしか無い。

- 専用のダイアログ
  - 「次の **すべて／いずれか** に一致」
  - 条件の行：`[項目] [演算子] [値]`、行の追加・削除
  - 項目：名前／ファミリー名／メモ／タグ／フォルダ／評価／お気に入り／ピン留め／言語／書体／太さ／特徴／形式／ファイルサイズ／追加日
  - 演算子：含む・含まない・等しい・以上・以下・範囲・〜日以内 など
  - 「一致：N 件」をリアルタイム表示
- データ：`Rule` を `{ match: "all" | "any", conditions: [...] }` に広げ、既存のルールは読み込み時に変換
- 今の「一覧上部の条件から作る」（⌘⇧⌥N）は残す

## まだ予定に入れていないもの（参考）

- タグ・評価・メモの CSV / JSON 書き出し
- アクション（条件に合うフォントへ自動でタグ付け・フォルダ移動）
- フォルダのタグを、そのフォルダへ入れたフォントへ自動で付ける
